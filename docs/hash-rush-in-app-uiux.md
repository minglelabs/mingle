# Hash Rush in HashChat: UI/UX requirements

작성: 2026-10-31. 근거: hash-rush `docs/UIUX-ISSUES.md`(#1~#231)와 2026-10-31 iPhone 11 Pro 실기기 확인.
목표: 웹에서 이미 겪은 UI/UX 문제를 앱 안에서는 다시 겪지 않게 한다. 웹에서 "불가"였던 것 중 앱이라 풀 수 있는 것은 푼다.

## 구조

- 앱(mingle) 채팅방 메뉴 "🌻 Hash Rush 같이 하기" → `HashRushSheet`가 게임 페이지를 iframe으로 연다.
- iframe 주소: `<NEXT_PUBLIC_HASH_RUSH_URL>?server=…&room=mingle-<chatId>&ticket=…&name=…&lang=…&embed=1`
- 게임은 G2 서버 방(방장 없음)에서 돌아간다. 한 채팅방 = 한 게임 방.

## 앱 ↔ 게임 메시지 (단일 규격, 양쪽이 이 표만 따른다)

`window.postMessage`로 주고받는다. 모든 메시지는 `{ source, type, ... }` 모양이다.
받는 쪽은 `source`가 맞지 않거나 `event.source`가 기대한 창이 아니면 버린다.

| 방향 | source | type | 내용 | 받는 쪽 동작 |
| --- | --- | --- | --- | --- |
| 게임 → 앱 | `hash-rush` | `ready` | `{ version: 1 }` | 로딩 표시를 끈다 |
| 게임 → 앱 | `hash-rush` | `keyboard` | `{ open: boolean }` | 열리는 동안 시트 높이를 바꾸지 않는다(아래 A5) |
| 게임 → 앱 | `hash-rush` | `phase` | `{ phase: 'lobby' \| 'round' \| 'results' }` | 기록용(지금은 동작 없음) |
| 앱 → 게임 | `hashchat` | `visibility` | `{ visible: boolean }` | `false`면 #228처럼 소리만 끄고 라운드는 계속. `true`면 소리 복귀 |
| 앱 → 게임 | `hashchat` | `voice` | `{ active: boolean }` | `true`면 배경음악만 끈다(효과음은 유지). `false`면 원래 설정으로 |

앱은 iframe `load` 때와 상태가 바뀔 때마다 `visibility`, `voice`를 보낸다. 게임은 `ready`를 보낸 뒤 받은 마지막 값을 따른다.

## 실기기 확인 목록 (iPhone)

- [ ] 시트가 아래에서 올라오고, 맵이 가로를 꽉 채운다
- [ ] 맵 스와이프·방향키 조작 중 시트가 내려가거나 채팅방에서 나가지지 않는다
- [ ] 화면 왼쪽 가장자리에서 스와이프해도 뒤로 가지 않는다
- [ ] 광고 배너가 안 보인다
- [ ] 게임 채팅: 키보드가 올라와도 시트·맵 크기가 그대로, ⌃⌄✓ 막대 없음, 입력 바가 키보드 바로 위
- [ ] 시트를 내리면 소리가 꺼지고 보이스톡은 계속, 다시 올리면 같은 판 그대로
- [ ] 보이스톡 중 배경음악 꺼짐, 효과음은 남
- [ ] "방 목록 보기 / 방 나가기 / 홈 화면 추가 / 진동" 안 보임

## v2 (2026-11-01): 대화는 해시챗 것으로

Nam 결정: Hash Rush는 대화방 안의 한 기능이다. 게임 안 대화는 해시챗의 채팅 UI와 통번역을 그대로 쓴다.
게임 자체 채팅은 앱 안에서 쓰지 않는다.

### 화면

- 시트는 대화방 상단바 아래부터 **해시챗 입력창 바로 위까지** 덮는다. 아래쪽은 원래 대화방 화면 그대로다:
  최근 메시지 2~3줄 + 해시챗 입력창(키보드 입력, Start 음성 통역, 사진 등 기존 버튼).
- 시트가 열린 동안 그 대화방의 말풍선 표시 방식은 **하나의 말풍선으로 표시(`collapsed`)**로 보인다.
  저장된 사용자 설정은 바꾸지 않는다(시트가 열려 있는 동안만 덮어쓴다).
- 최근 메시지 영역은 2~3줄 높이로 고정하고, 새 메시지가 오면 맨 아래로 붙는다. 위로 밀면 이전 메시지를 볼 수 있다.
- 빠른 채팅 칩(게임의 14개: ㄱㄱ, 잠만, ㅋㅋㅋ …)은 시트가 열린 동안 입력창 바로 위에 가로 스크롤로 보인다.
  누르면 일반 메시지로 보낸다(번역도 일반 메시지처럼).
- 키보드: 키보드가 올라오면 해시챗 입력창만 키보드 위로 올라가고, 시트(게임) 높이는 그대로다(UIUX-ISSUES #181).
  최근 메시지 영역은 입력창 바로 위에 붙어 함께 올라간다.
- 게임 중 대화는 일반 대화방 메시지로 저장된다(기록, 번역, 푸시, 코인 차감 모두 기존 그대로).

### 게임(hash-rush, embed=1)

- 게임 자체 채팅 UI를 모두 숨긴다: 💬 버튼, 채팅 바, 빠른 채팅, 대화록, 떠 있는 대화, 들어옴/나감 줄, 채팅 알림음.
- 서버에서 오는 `chat` 메시지는 화면에 띄우지 않는다(입장권 방에서는 서버가 `chat`을 받지도 보내지도 않아도 된다).
- 앱이 보내는 `chat` 메시지를 받아 보낸 사람 햄스터 머리 위 말풍선으로 띄운다(기존 말풍선 모양·시간 규칙 재사용).
- 로비 정보에 각 자리의 `userId`를 넣는다(입장권으로 들어온 자리만). 게임은 이것으로 말풍선 주인을 찾는다.

### 메시지 규격 추가

| 방향 | source | type | 내용 |
| --- | --- | --- | --- |
| 앱 → 게임 | `hashchat` | `chat` | `{ id, userId, text }` — `text`는 **보는 사람 언어로 번역된 글**(없으면 원문). 같은 `id`가 다시 오면(번역 도착) 말풍선 글만 바꾼다 |

위의 A1(시트 머리줄), A5(시트 높이)는 이 절이 대신한다.

### 서버 방 규칙 (방장 없음)

게임 서버(hash-rush `server/room.js`)가 방을 돌린다. 아무도 판을 시작하거나 요청하지 않는다. 화면 문구도 그렇게 쓴다.

- 대기실 8초 → 판 → 결과 9초(우승이 나온 판은 22초) → 대기실. 판은 저절로 시작된다. 사람이 4명보다 적으면 빈자리는 컴퓨터가 채운다.
- 앱 문구에 "방장"이 없다. 게임 문구 중 방장 관련 키(`waitingHost`, `waitingRematch`, `askAgain`, `askedAgain`, `hostWatch`, `again`)는 쓰지 않는다. "한 판 더" 버튼 대신 "다음 판은 N초 뒤 자동으로 시작해요"를 보인다.
- 승수와 누적 기록은 자리가 아니라 사람을 따라간다(입장권의 mingle 사용자, 없으면 브라우저 id). 나갔다 오면 자기 기록으로 돌아온다. 컴퓨터는 자기 자리 기록으로 뛴다.
- 10승을 먼저 하고 다른 쪽보다 2승 앞서면 우승이다. 같은 팀끼리 같으면 함께 우승한다. 두 쪽이 맨 위에서 같으면 듀스다. 우승 카드가 내려가면 기록이 처음부터 다시 시작되고, 지난 우승은 대기실에 남는다.

### 메시지 규격 추가 (서버 ↔ 앱)

| 방향 | 메시지 | 내용 |
| --- | --- | --- |
| 서버 → 앱 | `lobby` | 기존 필드에 더해 `nx`(다음 판까지 남은 ms, 없으면 -1), `fill`(한 판의 최소 햄스터 수 = 컴퓨터가 채우는 기준), `title: { wins: 10, lead: 2 }`, `tot`(자리별 누적: 꿀밤, 맞음, 해씨, 골인, 슈퍼, 던지기, 저지, 판 수), `hist`(지난 우승) |
| 서버 → 앱 | `over` | 판의 마지막 스냅샷 바로 뒤. `{ g, wins, tot, rd, champ, nx, title }`. 그 판이 들어간 기록과 우승 여부 |
| 앱 → 서버 | `stand` | 자리를 비우고 관전한다(판 도중에는 서버가 거절). 기록은 자리에 남아 다시 앉으면 돌아온다 |
| 앱 → 서버 | `sit` | 관전자가 빈자리에 앉는다. 판 도중이면 다음 판부터 뛴다 |

이전 서버(이 필드들이 없는 서버)에도 앱은 그대로 돈다. 그때는 카운트다운과 우승이 없고, 누적은 이 기기에서 센 것만 보인다.

- [ ] 맵 아래 조작 띠: 방향키·꿀밤이 집 줄을 덮지 않는다. 홈 인디케이터와 겹치지 않는다
- [ ] 상태 표시줄 글자가 연한 초록 띠 위에서 읽힌다(iOS 시계·배터리)
- [ ] ‹ 채팅 알약이 대기실·결과·우승 카드 위에서도 눌린다
- [ ] 판 소식 띠가 해바라기를 가리지 않는다
- [ ] 🏆 버튼과 ⚙ 버튼을 누를 때 방향키·꿀밤이 같이 눌리지 않는다
- [ ] 결과 카드가 뜰 때 꿀밤을 누르던 엄지에 카드가 바로 닫히지 않는다
