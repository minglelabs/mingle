## 2. 홈 = 사람 찾기

프로필 카드 2열 ✅. #544(`people-discovery-grid.tsx`, `GET /api/users/discover`)의 카드를 그대로 쓰고 자기소개 줄만 더한다.

- 카드: 큰 사진, '최근 접속' 배지, 국기 · 이름 · 나이, 쓰는 언어 ⇆ 배우는 언어와 실력 점, 자기소개 한 줄(길면 …, 없으면 빈 줄로 높이 맞춤).
- 운영 계정은 표시 없이 넣는다 ✅.
- 순서 ✅: 접속 중 → 언어가 맞는 사람 → 최근 접속 순.
  - 🔎 #544의 지금 순서는 '반대편(한국인 ⇄ 외국인) → 사진 있는 사람 → `lastSeenAt`'이다. '접속 중'을 맨 앞 단계로 추가해야 한다.
  - ❓ '접속 중'의 기준. 제안: `lastSeenAt`이 5분 이내. (`lastSeenAt`이 얼마나 자주 갱신되는지는 ⚠️ 확인 못 함)
- 카드를 누르면 프로필이 열린다. 한 번에 인사하기는 넣지 않는다 ✅.
- #544와의 관계: #544는 카드를 탐색 탭(검색어가 빈 화면)에 넣는다. 홈 탭이 생기면 그 격자를 홈으로 옮기고, 탐색의 빈 화면은 오픈방 목록이 된다. **#544를 먼저 머지하고 그 위에서 옮기는 것을 제안한다** ❓.

## 4. 방 두 종류 (사용자에게는 둘, 엔진은 하나) ✅

| | 오픈방 | 대화방 |
|---|---|---|
| 만드는 곳 | 탐색 | 대화목록 |
| 들어오는 법 | 누구나, 또는 비밀번호 | 초대와 링크 |
| 보이는 곳 | 탐색과 검색, 탐색의 '참여 중인 방' | 대화목록 |

- 종류 구분: 기획은 `kind` 칸 추가였다. **#377의 `is_public`이 같은 뜻이므로 그것을 쓰고 `kind`는 만들지 않는 것을 제안한다** ❓. '공개방은 대화목록에 넣지 않는다'는 규칙만 더하면 된다.
  - ⚠️ #377에서 공개방이 지금 대화목록에 보이는지는 확인 못 함. 머지 뒤 확인한다.
- 오픈방에만 새로 필요한 것 (#377 위에 추가): 비밀번호(해시로 저장, 시도 횟수 제한), 주제 태그, 방장 설정.
- 아무도 없어도 닫히지 않는다. 초기에는 운영진이 여는 상시 방으로 목록을 채운다 ✅.

### 오픈방 안의 보이스톡: 무대와 듣는 사람

기획(무대 8자리, 들어가면 듣는 사람으로 연결, 손들기, 무대 초대, 방장 권한)은 **보이스톡 기능 자체를 고치는 일**이다. #377은 전원 발언자 8명이고 듣는 사람 역할이 없다.

- ❓ 이것은 #377이 배포된 뒤 2차로 하고, 그 전까지 오픈방의 보이스톡은 #377 그대로(8명, 직접 참여 버튼) 쓰는 것을 제안한다. 보이스톡 브랜치 담당 세션과 나눠야 하는 일이다.
- 들어와 있는 모든 사람의 작은 동그라미 줄(누르면 프로필 → DM)은 #377의 `room-presence`로 만들 수 있다. 보이스톡과 무관하므로 1차에 넣는다.
- 대화방에서 보이스톡 진행 중일 때 "🎙 보이스톡 중 · 참여" 띠: #377의 판이 이미 하는 일인지 머지 뒤 확인하고, 있으면 만들지 않는다.
