# 온보딩: 말해 보기 → 로그인 → 초대권 (2026-11-13)

새 기기의 첫 실행 흐름이다.

1. 언어 설정 (기존 `LanguageOnboardingModal`)
2. **말해 보기**: 로그인 전, 메뉴·뒤로가기 없는 방에서 10초 동안 말해 본다 (`components/onboarding/speak-trial.tsx`).
   - 헤더에 카운트다운 링이 있다. 남은 초를 숫자로 보여 주고, 초록에서 빨강으로 바뀌며 줄어든다.
   - 마이크를 켜는 순간부터 10초를 센다. 시간이 끝나거나 사용자가 먼저 끄면 마무리한다. 마지막 번역을 1.8초 기다린 뒤 "어땠어요?" 카드에서 문장 길이 3칸을 고른다. 기본값은 가운데(추천, 자동감지 5/5)다.
   - 고른 길이는 로그인 뒤 계정에 저장된다 (`lib/speak-trial.ts`, `takePendingSpeechLength`). 이 경우 첫 방의 길이 카드는 다시 뜨지 않는다.
   - 기기당 1번만 나온다. 이 기기에서 로그인한 적이 있으면 건너뛴다. "이미 계정이 있어요"를 누르면 바로 로그인으로 간다.
   - STT 서버와 번역 API는 원래 로그인 없이 동작하므로 서버 변경은 없다. 남용은 클라이언트의 10초 제한과 기기당 1회로만 막는다.
3. **로그인**: 맨 위에 "전화번호로 계속하기"가 생겼다. Apple, Google, 이메일은 그대로다.
   - 문자로 받은 6자리 코드로 로그인한다. 처음 쓰는 번호면 계정이 바로 생긴다 (NextAuth provider `phone-code`).
   - 그 번호는 인증된 번호로 저장되므로, 연락처로 친구 찾기에 그대로 쓰인다.
   - 버튼은 서버가 코드를 보낼 수 있을 때만 보인다 (`GET /phone/sign-in`).
4. **초대권**: 서버에서 `INVITE_GATE=on`이면 초대받지 않은 새 계정에 초대 코드 입력 화면이 뜬다 (`components/onboarding/invite-gate.tsx`, `server/app-access.ts`).
   - 코드를 넣으면 기존 초대와 똑같이 처리된다. 양쪽이 보상 코인을 받고 서로 팔로우한다.
   - 초대 링크로 들어온 사람은 자동으로 통과한다.

## 환경변수 (Railway, mingle-2-0-0)

| 변수 | 뜻 |
|---|---|
| `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_VERIFY_SERVICE_SID` | 문자 인증. 없으면 운영에서는 전화번호 로그인 버튼이 숨겨진다. |
| `PHONE_REVIEW_LOGINS` | 심사용 번호와 고정 코드. 예: `+821000000000:123456,+15555550100:654321`. 문자를 보내지 않고 이 코드만 받는다. |
| `REVIEW_ACCOUNT_EMAILS` | 초대권 확인을 건너뛰는 심사용 이메일 계정 (쉼표로 구분). |
| `INVITE_GATE` | `on`이면 초대권 확인을 켠다. 기본은 꺼짐. |
| `INVITE_GATE_SINCE` | ISO 날짜. 이 시각 이전에 만든 계정은 초대 없이 계속 쓴다. 비워 두면 모든 계정에 적용된다. |

초대권 확인을 켤 때는 기존 유저가 막히지 않게 `INVITE_GATE_SINCE`를 켜는 시각으로 꼭 넣는다.

## 앱 심사

- App Store Connect의 "앱 심사 정보"와 Google Play의 "앱 액세스"에 심사용 번호와 코드를 적는다. 예: "+82 10-0000-0000, 인증번호 123456".
- 그 번호는 `PHONE_REVIEW_LOGINS`에 넣는다. 심사 계정은 초대권 없이 들어간다.
- 기존 이메일 심사 계정을 계속 쓰려면 `REVIEW_ACCOUNT_EMAILS`에도 넣는다.

## 문자 비용·남용

- 로그인 전 코드 요청 한도는 번호당 하루 5번, IP당 하루 10번이다. 서버 메모리에 저장되므로 재시작하면 초기화된다. Twilio Verify 자체의 번호당 한도는 따로 남아 있다.
- Twilio 콘솔에서 Verify Fraud Guard와 Geo Permissions(허용 국가)를 켠다. 국제 SMS pumping을 막기 위해서다.

## 연락처 연동

- 번호로 가입하면 번호가 바로 인증되므로, "연락처에서 친구 찾기"를 추가 인증 없이 쓸 수 있다.
- 연락처 접근을 가입 필수로 만들지는 않는다. Apple 가이드라인 5.1.1은 앱 기능에 꼭 필요하지 않은 권한을 강제하지 못하게 하고, 거절하면 심사에서 반려된다. 대신 첫 방을 나온 뒤 권하는 현재 흐름을 유지한다.
