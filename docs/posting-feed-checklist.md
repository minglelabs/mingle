16. 펼쳐보기 -- 새 페이지나 모달로 이동하지 않고 현재 게시물 위에서 본문 영역을 위로 확장

95. 알림 설정·읽음 -- 앱 내 알림은 전체 알림 켜기·끄기만 제공(세부 설정은 후속, 초기값 켜짐); 통합 알림 목록을 열면 진입 시점까지 도착한 모든 알림을 일괄 읽음 처리하고 모두 읽음 버튼은 두지 않기; 읽음 상태를 계정별 DB에 저장해 다른 기기와 피드·대화목록의 미확인 표시에도 반영; 대화 메시지의 읽음 상태와는 별도; 미확인 알림이 있으면 피드·대화목록의 종 아이콘에 숫자 없이 작은 빨간 점; 알림 목록 진입으로 전체 읽음 처리되면 두 화면과 다른 기기의 빨간 점도 제거
96. 원댓글 삭제 -- 답글이 없으면 댓글을 숨기고, 답글이 있으면 원댓글 본문 대신 "삭제된 댓글입니다"; 다른 사람이 작성한 답글은 유지; DB 레코드는 물리 삭제하지 않고 삭제 상태만 변경
97. 댓글 정렬 -- 원댓글과 답글을 모두 오래된 순으로, 원댓글 아래에 해당 답글을 시간순으로 묶기
98. 통합 검색 -- 탐색 탭의 검색창 하나로 사람·게시물을 함께 검색; 사람은 상단 최대 3명과 모두 보기, 게시물은 아래 3열 썸네일, 스크롤 시 추가 로딩; 사람 모두 보기는 오른쪽에서 슬라이딩되는 별도 전체 목록 화면, 그 화면에서 사람 추가 로딩; 뒤로 가면 검색어·결과·스크롤 위치 유지; 결과가 없는 영역은 생략하고 둘 다 없으면 "검색 결과 없음"; 한 글자부터 검색, 마지막 입력 후 300ms 디바운스, 한글 조합 중에는 요청하지 않기; 지우기 버튼으로 검색어 삭제 시 기본 탐색 화면; 사람은 표시 이름·handle 검색, anon_ handle 제외; 게시물 원문과 이미 생성된 번역문을 검색하되 검색용 추가 번역은 만들지 않기; 같은 게시물은 한 번만; 게시물은 안 본 글·팔로우 우선 없이 반응 점수순(좋아요 x 1 + 고유 댓글 작성자 수 x 2), 동점일 때만 최신순; 비공개·보관·삭제·상호 차단·본인 숨김 제외; 썸네일은 프로필과 같은 정책; 게시물 선택 시 전체화면, 검색 결과 게시물만 위아래로 넘겨보기(홈 피드 섞지 않음); 뒤로 가면 검색어·결과·스크롤 복원; 대화방 검색·대화방 공개 설정은 범위 밖; 사람 정렬은 정확 일치 -> 앞부분 일치 -> 중간 포함, 같은 단계는 현재 사람 목록 정렬 유지, 차단 사용자·anon_ 제외; 사람 선택 시 기존 프로필, 돌아오면 검색 상태 복원; 검색어가 없을 때는 검색창만(추천 없음); 포커스 시 입력이 비어 있으면 계정별 DB의 최근 검색어 최신순 최대 10개, 기기 간 공유; 최근 검색어 30일 보관, 중복은 최신 시각으로 갱신; 최근 검색어 탭 시 재검색, 개별 삭제·전체 삭제; 3열 썸네일에는 좋아요·댓글 수 표시하지 않기; 새 결과를 불러오는 동안 기존 결과 유지하고 검색창 주변에 작은 로딩 표시만; 기존 결과가 없는 첫 검색 중에는 결과 영역을 비워두고 스켈레톤·전체 로딩 화면 없음; 검색 실패도 별도 오류 문구·재시도 없이 "검색 결과 없음"
