# HashChat 포지셔닝: 한국인-외국인 교류·언어교환 (2026-11-14)

이름은 HashChat 그대로 둔다. "통번역 메신저"에서 **한국인과 외국인이 친구가 되는 교류·언어교환 앱**으로 바꾼다. 통역은 첫 번째 차별점으로 그대로 내세우되, "말이 서툴러도 바로 친구가 된다"는 이유로 쓴다.

바꾸는 곳: 스토어(App Store, Google Play), 스토어 스크린샷, 홈페이지(`mingle-landing`), 앱의 공유 카드와 권한 문구. **블로그(`mingle-app/scripts/legal-blog-i18n`)는 바꾸지 않는다.**

## 누구에게

| 대상 | 원하는 것 |
|---|---|
| 외국인 (K-콘텐츠 팬, 한국어 학습자, 한국 여행 예정자) | 한국인 친구, 한국어 연습, 한국 현지 정보 |
| 한국인 | 외국인 친구, 외국어 연습, 해외 현지 정보 |

**한국어 페이지는 한국인에게, 나머지 언어는 외국인(한국인 친구를 찾는 사람)에게** 말한다.

## 차별점 (이 순서)

1. **실시간 통번역**: 말이 서툴러도 대화가 돼요. 채팅은 서로 자기 언어로 읽고, 음성 대화는 실시간으로 통역돼요. 언어교환이 첫날부터 돼요.
2. **진솔한 대화**: 변태나 사기꾼 걱정 없이 진짜 친구를 사귀는 곳. 신고와 차단은 한 번에, 운영진이 신고를 확인해요.
   - "인증된 한국인", "초대제"는 앞에 내세우지 않는다(바이럴 장치이지 소개 문구가 아니다).
3. **함께 즐길 거리**: 피드에서 친구들의 일상을 내 언어로 읽고 댓글을 달아요. 친구와 미니게임(해시 러시)도 해요.
4. **현지 친구의 추천 (관광은 가볍게)**: 한국에 오기 전에 현지 친구를 사귀고, 미용실·병원·맛집을 추천받아요. 예약 전화도 HashChat 통역으로 걸어 보세요.
   - 한국어 페이지에서는 거꾸로: 외국인 친구에게 한국을 소개하고, 해외여행 갈 땐 현지 친구에게 추천받아요.

| 한 줄 | 외국인 친구, 말이 안 통해도 사귈 수 있어요 | Make Korean friends, even before your Korean is good |

## 검색어는 옛것까지 유지

스토어 키워드와 설명 끝부분에 옛 검색어가 계속 남아 있어야 한다. 옛 정보로 찾아도 나오게 하기 위해서다.
- 새로 앞에 두는 말: 언어교환, 외국인친구, 한국인친구, 펜팔, 한국어공부, 한국여행 (각 언어로)
- 지우지 않는 말: 해시챗·밍글 계열(현지 문자 포함), 번역기·통역·동시통역·실시간자막 계열, 영어 `translator,easiest,global,hangout,mingle`
- 키워드 칸이 모자라면 새 말 일부를 설명 본문으로 옮기고, 옛 검색어를 남긴다. `docs/store-metadata-pending.md`의 유지 규칙을 따른다.
- 설명 맨 끝에 "실시간 음성 번역기, 동시통역, 실시간 자막" 같은 옛 기능 이름을 한 문단으로 남긴다.

## 스크린샷 (8장)

| # | 내용 |
|---|---|
| 01 | 여러 나라 친구들 사진. "한국인 친구를 사귀어요" |
| 02 | 1:1 채팅, 서로 자기 언어로 (통번역, 차별점 1) |
| 03 | 음성 대화 실시간 통역 (차별점 1) |
| 04 | 진솔한 대화: 친구와의 따뜻한 대화 장면, "변태·사기꾼 걱정 없이" (차별점 2) |
| 05 | 피드 글을 내 언어로 (차별점 3) |
| 06 | 현지 친구에게 미용실·병원 추천받기 + 통역 예약 전화 (차별점 4) |
| 07–08 | 해시 러시 게임 (차별점 3) |
