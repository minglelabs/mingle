Mingle External Relations

Shared presentation format for IR, PR, and HR conversations. Each slide keeps only a title and a body so the deck stays clean before content is filled in.

Title

Use this area for the one message that the audience needs to understand on this slide. Keep the body concise and let the title carry the primary emphasis.

Body

This template keeps the structure deliberately minimal. Navigation still loops, the slide motion stays horizontal, and the layout leaves room for narrative decisions later.

Loop

The last slide returns to the first slide, and moving backward from the first slide returns here. Arrow keys and wheel input both follow the same cycle.
